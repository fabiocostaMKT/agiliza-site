*Agilizou… chegou!*

## Publicar

É um site estático (HTML, CSS e JS num arquivo só), sem build:

- **GitHub Pages:** já está ligado neste repositório.
- **Outra hospedagem:** suba `index.html` e a pasta `assets/` para a pasta pública (ex.: `public_html`).
- **Netlify:** arraste a pasta em app.netlify.com/drop.
